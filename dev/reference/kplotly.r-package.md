# kplotly.r: Concise, Composable Interactive Plots from a Single Call

Draw a complete interactive 'plotly.js' graphic (data reshaping, series,
colours, labels, theme, legend, range slider) with a single short call,
and compose plots with the '+' operator through the 'kplotly' S3 class.
The 'plotly.js' library is embedded, so the package only depends on
'htmlwidgets'. Plot types, themes and palettes live in extensible
registries.
